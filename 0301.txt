-> Open Terminal(cmd or PowerShell)
-> Run Command : winget install Oracle.JDK.23
-> Open PowerShell as Administrator
-> Run Command : [Environment]::SetEnvironmentVariable("JAVA_HOME", "C:\Program
Files\Java\jdk-23", "Machine")
-> Run Command : [Environment]::SetEnvironmentVariable("Path", $env:Path +
";C:\Program Files\Java\jdk-23\bin", "Machine")
-> Run Command : java -version (If Version is shown java installed successfully)
